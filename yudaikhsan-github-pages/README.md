# yudaikhsan.github.io

Academic website for Yudha Ikhsan, designed as a lightweight static site for GitHub Pages.

## Structure

- `index.html` — homepage
- `research.html` — working, published, and in-progress research
- `projects.html` — project portfolio
- `posts.html` — Substack/Thoughts landing page
- `cv.html` — curriculum vitae
- `contact.html` — contact details and email form
- `styles.css` — shared design system
- `script.js` — mobile navigation, current year, and email-form behavior

## Publish

Upload these files to the root of the `main` branch. In repository settings, ensure **Pages → Deploy from a branch → main / root** is selected.

## Before publishing

Replace placeholder paper, project, CV, PDF, DOI, slides, code, and demo links marked with `#`.
